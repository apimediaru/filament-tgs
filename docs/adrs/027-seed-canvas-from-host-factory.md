# ADR-027. Сохранение ТГС из фабрики

`withTgs()` собирает рецепты в порядке вызовов для каждой группы. При `create()`
фабрика сохраняет каждый хост вместе со всеми его канвасами и медиа в собственной
транзакции на общем соединении. Такой порядок сохраняет готовые статьи из
пачки при сбое следующей. Обработчик Laravel `afterCreating()` видит готовые
блоки, а его ошибка до коммита откатывает эту статью.

Пакет сверяет весь новый набор со слотами и правилами размещения зарегистрированных
дескрипторов. Затем он использует текущий импорт дерева. Импорт сохранённых
снимков и `BlockTree` сохраняют свой контракт, в том числе чтение старых типов.
Новый блок может предоставить собственный типизированный `seed()` поверх
общего `BlockSpec`. Дескриптор задаёт доступность блока, его слоты и явный
диск медиа. Общие правила продолжают действовать для всех блоков.

Файлы записывает Spatie. Очистка привязана к фактическому откату БД, включая
откат окружающей транзакции. При исключении после успешного коммита файлы
принадлежат сохранённым записям. Синхронно созданные конверсии очищаются вместе
с оригиналами при откате. Для асинхронных конверсий используйте запуск очереди
после коммита. Очистка требует работающего хранилища и выполнения обработчика отката.
