# Доменные термины

Термины, зафиксированные на гриллинге. Уровень — домен, не реализация.

- **ТГС / Tgs** — конструктор блоков: блок как сущность, канвас как контейнер размещений, reuse,
  история, корзина. Единственное имя; `Tgb` не используется.
- **Хост (TgsHost)** — модель сайта, владеющая host-канвасом (News, Article, Page). Пакет узнаёт о
  хостах только через регистрацию.
- **Владелец embedded-канваса** — тот, кто *заклеймил* канвас. Не обязан быть моделью (ManageAbout —
  JSON в settings). Незаклеймленный канвас старше grace-окна — мусор.
- **Клейм (claim)** — акт владельца «эти embedded-канвасы мои, вот их ключи кэша».
- **Дескриптор типа блока** — единственный источник правды о типе: форма, DTO, дети, политика, превью.
- **Категория блока** — группа в палитре редактора (Layout, Media, ...). Объект, расширяемый сайтом.
- **Реестр блоков** — набор дескрипторов после применения дельты сайта (add / hide).
- **Дельта сайта** — добавления и скрытия поверх дефолтного набора блоков и категорий.
- **Workbench** — минимальная витрина пакета для визуальной проверки; не копия стартера.


# Стартер — ТГС

ТГС позволяет собирать содержимое из блоков и переиспользовать его в разных местах сайта.

## Language

**Встроенный канвас (embedded canvas)**:
Самостоятельное содержимое внутри элемента формы, например ответ на вопрос FAQ. Его владелец хранит ссылку на канвас.

**Клейм канваса (canvas claim)**:
Отметка о том, что один сохранённый владелец использует встроенный канвас. Клейм относится к канвасу целиком, а не к правам на отдельные блоки.
_Avoid_: Блокировка редактирования.

**Освобождение канваса**:
Прекращение использования встроенного канваса его сохранённым владельцем. Освобождённое содержимое временно сохраняется перед очисткой.

**Заготовка встроенного канваса**:
Канвас, созданный при редактировании формы, но ещё не закреплённый за сохранённым владельцем.
