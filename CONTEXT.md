# ТГС — текстово-графический строитель

Доменный словарь: [GLOSSARY.md](GLOSSARY.md). Решение о выделении пакета:
[ADR-024](docs/adrs/024-tgs-extracted-to-composer-package.md).
Установка, контракты и Workbench: [README.md](README.md).

Пакет владеет канвасами, блоками, размещениями, медиа блоков, коллекциями,
историей, корзиной и клеймами встроенных канвасов. Сайт владеет моделями контента,
пользователями, ролями, правами, настройками и ответом собственного API.
Интеграция идёт через TgsPlugin, контракты хостов, конфиг и Gate abilities.
Префикс таблиц — tgs_; namespace — ApiMedia\Tgs; пользовательский JSON сохраняется.

Состояние B8, 2026-11-06: ядро перенесено из стартера, установлено через path Composer.
Следующий этап B9 — ревью релиза, документация расширения и публикация 0.1.0.
