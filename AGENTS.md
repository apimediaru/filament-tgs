# Работа с ТГС

Пиши пользователю по-русски. Доменный словарь — GLOSSARY.md; архитектура — docs/adrs.

Развивай src через публичные контракты: сначала воспроизводящий тест, затем реализация.
Код пакета независим от App и сырого SQL; проверки архитектуры обязательны.
Конфигурация приложения регистрируется через TgsPlugin; состояние запросов — scoped.
Сохраняй публичный JSON и правила ownership/reuse/history/claims при рефакторинге.

Команды проверки определены в composer.json. Сначала целевые тесты, затем полный набор,
анализ и стиль. В Docker-стартере запускай их в контейнере app из /var/www/filament-tgs;
сам пакет допускает обычное PHP-окружение. Проверяй fresh SQLite и PostgreSQL при изменении схемы.
Публикация и теги — отдельный согласованный релиз; commit messages на английском, в формате Conventional Commits.
