# Библиотека и коллекции

Библиотека хранит блоки для повторного использования. Коллекции позволяют организовать заготовки по смыслу, например наборы для промостраниц. Наличие заготовки ещё не размещает её на странице.

## Вставить заготовку

1. Откройте нужное место в редакторе.
2. Выберите вставку существующего блока.
3. Найдите заготовку в библиотеке или нужной коллекции.
4. Выберите вставку копией или ссылкой.
5. Подтвердите вставку и проверьте результат.

Если заготовка содержит вложенные блоки, возможность вставки проверяется для всего поддерева. Неподходящая заготовка может быть недоступна для выбранного места.

## Подготовить повторно используемый блок

Откройте библиотеку или коллекцию в разделе ТГС и создайте блок в её редакторе. Для существующего содержимого страницы используйте доступное действие переноса в библиотеку. Перед подтверждением прочитайте последствия операции.

Пример. Сохраните типовой контактный блок в библиотеке. Вставляйте его ссылкой там, где контакты должны обновляться вместе, или копией для отдельного филиала.

Блок, принадлежащий библиотеке, может открываться на странице только для просмотра. Изменяйте его в источнике либо используйте «Открепить», чтобы получить независимую копию. Подробнее — в главе «Копии и ссылки».
