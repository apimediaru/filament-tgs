# Удаление и восстановление

Перед подтверждением прочитайте диалог удаления. Доступные действия зависят от владельца блока, количества размещений и ваших прав.

| Действие | Результат |
| --- | --- |
| Убрать со страницы / убрать только это размещение | Снимается выбранное размещение. Другие места использования сохраняются |
| Удалить везде | Общий блок убирается из всех мест и попадает в корзину |

Обычное удаление собственного блока может также затронуть вложенное содержимое. Диалог показывает предупреждение. После снятия последнего размещения блок может оказаться среди осиротевших.

## Восстановить блок

1. Откройте «Корзина» в редакторе.
2. Найдите нужную операцию удаления.
3. Нажмите «Вернуть».
4. Проверьте восстановленное содержимое и его положение.

Если исходная позиция уже недоступна, блок может вернуться на другое место. Прочитайте уведомление и проверьте редактор.

После «Удалить везде» восстановление возвращает блок только в одно место. Остальные размещения автоматически не возвращаются. При необходимости создайте их заново.

Пример. Блок стоял на трёх страницах. Чтобы убрать его с одной, выберите удаление только этого размещения. Выбор «Удалить везде» затронет все три страницы.

В стандартной конфигурации срок хранения корзины составляет 60 дней. Проект может изменить этот срок. После окончательной очистки восстановление через корзину недоступно. Если действие запрещено блокировкой или правами, обратитесь к администратору.
