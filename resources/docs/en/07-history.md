# Change history

History lets you inspect saved block changes and restore an available version. It concerns block content. Shared-block placements, page fields and trash recovery have their own workflows.

## Inspect changes

1. Open the block's history action.
2. Find an entry by time and available author information.
3. Open the change view («Смотреть» in Russian).
4. Compare the values before restoring.

## Restore a version

Choose the available restore action («Восстановить») for the required version. After confirmation, check the block fields and its editor preview.

Restoring shared content affects every placement. Locks and permissions can prevent restoration. Check where the block is used before proceeding.

For example, an incorrect phone number was saved in a shared block. Find the previous version, verify the correct number and restore it. Check the pages using that shared block.

To recover a deleted block, use trash. Edit page titles and publication status through the main record form.
