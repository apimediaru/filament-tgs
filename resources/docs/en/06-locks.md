# Locks and read-only mode

Read-only mode lets you inspect content while changes are restricted. It can apply to the whole editor or one block because of permissions, a lock or ownership by another source.

## When editing is unavailable

1. Check the block's lock or linked-content indicator.
2. For a library-owned block, open its source to edit it.
3. For an administrator lock, ask an administrator to review the change.
4. Use the available detach action if an independent copy is required.

A parent lock can cover its nested content. A shared block reachable through multiple paths can remain protected when one of those paths is locked.

## Manage a lock

With the required permission, open the block's lock action and confirm it. Use unlock to remove the lock. Russian labels are «Заблокировать» and «Разблокировать». Available actions follow the site's permissions.

For example, an administrator protects shared legal wording against accidental edits by managers. Managers can still read the text and ask an administrator to change it.

Read-only mode preserves access to the content and its guide. Action visibility follows the site's current permissions.
