# Adding and editing blocks

TGS builds page content from blocks. Text, an image and a two-column layout can be separate blocks. Your site determines the available block types.

## Add content

1. Open the page or news item in the admin panel and locate the block editor.
2. Use the add-block control at the required position. In the Russian interface it is labelled «Добавить блок».
3. Select a type allowed at that position.
4. Complete the block form, including its required fields.
5. Confirm creation using the form's submit button.

The block appears in the editor. Cancelling before confirmation leaves it unplaced.

## Edit a block

Open the block's edit action, change its fields and submit the block form. Heading and section settings, where available, control that block's presentation. The available fields depend on the type and site configuration.

The editor saves confirmed block operations as you work. Wait for the save indicator. Save the page title, status and other record fields using the main form button. When creating a record, complete creation of the page or news item itself.

For example, correct a typo by opening the text block and saving its form. For a shared block, first check its other uses as described in “Copies and references”.

If only viewing is available, check the lock state or contact an administrator. Some controls may retain their Russian labels on a customised site.
