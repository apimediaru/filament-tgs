# Block order and nesting

The editor's block order determines content order. Some blocks provide child areas, such as left and right columns.

## Move a block

1. Find its drag handle.
2. Drag it to the required position or an available container area.
3. Release it and wait for saving to complete.
4. Check its new order and nesting.

For example, drag an image below text within the same area to place it after the text. To put it in the right column, move it into the column block's corresponding area.

## Add a nested block

Use the add control inside the target container area. Available types depend on that area and site rules. Edit nested blocks through their own forms.

An incompatible move can be rejected. A block cannot contain itself or its ancestors. A parent lock can also prevent insertion or movement.

Create a suitable container first when you need columns. The saved tree defines placement, while the site's presentation depends on the project design.
