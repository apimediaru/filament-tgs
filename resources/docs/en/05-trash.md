# Deletion and recovery

Read the confirmation before deleting. Available actions depend on ownership, placement count and your permissions.

| Action | Result |
| --- | --- |
| Remove from page / remove this placement only | Removes the selected placement and preserves other uses |
| Delete everywhere | Removes the shared block from every location and sends it to trash |

Deleting an owned block may also affect its nested content. Read the dialog warning. A block with its last placement removed may appear among orphaned blocks.

## Restore a block

1. Open the editor's trash («Корзина» in Russian).
2. Find the required deletion entry.
3. Choose restore («Вернуть»).
4. Check the restored content and its position.

When the original position is unavailable, the block can return to another position. Read the notification and inspect the editor.

Restoring after “Delete everywhere” returns the block to one location only. Other placements are not recreated automatically. Add them again if needed.

For example, a block appears on three pages. To remove it from one page, remove that placement only. Deleting everywhere affects all three pages.

The default trash retention is 60 days. A project can change it. After permanent cleanup, trash recovery is unavailable. Contact an administrator if a lock or permission prevents the required action.
