# Library and collections

The library stores reusable blocks. Collections organise templates by purpose, for example material for promotional pages. Storing a template does not place it on a page.

## Insert a template

1. Open the target position in the editor.
2. Choose insertion of an existing block.
3. Select a block from the library or a collection.
4. Choose a copy or a reference.
5. Confirm insertion and check the result.

For a template with children, the complete subtree must be allowed at the destination. An incompatible template can be unavailable there.

## Prepare reusable content

Open the library or a collection in the TGS section and create a block in its editor. For content already on a page, use its available move-to-library action and read the confirmation before proceeding.

For example, keep a standard contact block in the library. Insert a reference where contact details should change together, or a copy for an independent branch office.

A library-owned block may be view-only on a page. Edit it in its source or use the detach action («Открепить» in Russian) to create an independent copy. See “Copies and references”.
