# Copies and references

When inserting an existing block, decide whether future changes should be shared.

| Method | Result |
| --- | --- |
| Copy | Creates an independent block. Editing it leaves the original intact |
| Reference | Reuses the shared block. Editing it affects every placement |

## Choose an insertion method

1. Open insertion of an existing block.
2. Select the template.
3. Choose copy or reference in the insertion-method field. Russian labels are «Копией» and «Ссылкой».
4. Confirm insertion.

For example, the home page and contact page reference one contact block. Changing its phone number updates both placements. Use a copy for a branch office with separate details.

## Make a placement independent

Use the shared block's detach action («Открепить»). Confirm creation of an independent copy. If the form offers detaching nested references too, select it when nested shared content also needs to become independent.

Before editing shared content, inspect its available usage information. A block owned elsewhere may be view-only here and editable in its library or other source. Permissions and locks affect detaching.

Removing a single placement and deleting the shared block everywhere have different consequences. See “Deletion and recovery”.
